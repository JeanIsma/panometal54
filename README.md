# PanoMetal54 Final Website

## Start on Windows

Double-click `START-PANOMETAL54.bat`.

The website uses Node.js only as a reliable local web server. It does not require npm install, Vite, Three.js downloads, or any private registry.

The browser opens automatically. The normal address is:

`http://localhost:5173/`

If port 5173 is already occupied, the launcher automatically tries 5174 through 5183 and opens the correct address.

Keep the black server window open while viewing the site. Press Ctrl+C to stop it.

## Edit and rebuild

Edit the files under `src/`, then double-click `BUILD-WEBSITE.bat`. The updated hosting files will be written to `dist/`.
