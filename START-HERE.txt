PANOMETAL54 FINAL FIXED VERSION
==============================

1. Extract the ZIP to a normal Windows folder.
2. Double-click START-PANOMETAL54.bat.
3. Keep the black window open.
4. The browser opens automatically at http://localhost:5173/

If port 5173 is already occupied, the launcher tries 5174 through 5183 and opens the correct address automatically.

This version does NOT run npm install and does NOT require Vite. Node.js is used only as a reliable local web server, so the starter no longer closes silently because of a dependency-install error.
